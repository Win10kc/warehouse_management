Luồng dữ liệu chính:
  1. Yêu cầu nghiệp vụ: Thiết bị di động gửi payload (SKU, mã QR/RFID, vị trí Bin) lên API dưới dạng chuỗi JSON rắn.
  2. Xử lý trung tâm: Backend xác thực JWT , đóng gói logic nghiệp vụ vào một Database Transaction duy nhất nhằm tránh tranh chấp dữ liệu (Race Condition).
  3. Đồng bộ Real-time: Ngay khi lệnh hoàn tất được xác nhận (`Complete`), dữ liệu tồn kho được lưu xuống Postgres đồng thời kích hoạt cổng trục Redis để WebSocket Hub phát thông điệp (`stock_update`, `alert`) tới toàn bộ các Client đang kết nối.
